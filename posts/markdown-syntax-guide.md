# 지원하는 마크다운 문법

이 파서는 외부 라이브러리 없이 **자체 구현**되어 있습니다.
아래는 현재 지원하는 문법 목록입니다.

## 헤딩

`#` 부터 `######` 까지 여섯 단계를 지원합니다.

## 텍스트 강조

**굵게**, *기울임*, __또 다른 굵게__, _또 다른 기울임_,
그리고 `인라인 코드` 를 쓸 수 있습니다.

## 리스트

순서 없는 리스트:

- 첫 번째 항목
- 두 번째 항목에는 **강조**를 넣을 수 있습니다
- 세 번째 항목에는 `코드`도 됩니다

순서 있는 리스트:

1. 파일을 읽는다
2. front matter를 파싱한다
3. HTML로 변환한다

## 코드블록

```js
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("world"));
```

이스케이프도 처리합니다:

```html
<div class="box">a &amp; b < c</div>
```

## 인용문

> 좋은 도구는 사용자가 도구를 잊게 만든다.
>
> 그리고 인용문 안에서도 **강조**가 동작합니다.
